# 公开内容与隐私边界

我采用文件白名单发布：Python源码、免费测试、通用Windows脚本、示例配置和本文档。我将真实运行数据与公开代码分开保存，不会把运行目录整体压缩上传。

## 不公开的内容

- articles.db、其他数据库、WAL/SHM和全部备份。
- image_store、真实文章正文、海报、分析结果、reports和logs。
- 真实OPML、订阅地址、RSS Token/Secret、授权文件、Cookie与登录会话。
- DEEPSEEK_API_KEY的值、云平台密钥、环境变量导出文件。
- 本机用户名和私人目录、真实部署域名、个人控制台链接。
- 下载的云端工具二进制与第三方商业软件镜像。

config.example.json只有公开测试源，付费开关关闭。真正运行时复制为本地config.json，该文件被.gitignore排除。已提交的文件不会因为后补.gitignore就从历史消失，因此不要在仓库中编辑真实密钥后再试图删除；发现泄露应撤销相关凭据并检查历史。

## 发布方式

建议将该副本放入一个全新的仓库，避免带入旧提交或本地数据。GitHub网页可上传本文件夹中的源码与docs目录；不要只上传zip而不展开，否则读者难以浏览代码。zip适合做可选的Release附件。

我在仓库中同时提供可浏览源码与下载包，尚未为代码选择LICENSE。云端服务和DeepSeek的技术方法以文档说明，不公开凭据、数据或账单截图。

自动任务属于原运行目录，公开副本没有被注册为新的任务。修改或测试公开副本不会关闭原项目的每日任务。
